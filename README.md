# FreeStyle Libre Website Recreation

A frontend recreation of the FreeStyle Libre healthcare professional website created as a learning and portfolio project.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery
- Slick Carousel

## Features

- Header and navigation
- Hero section
- Image carousel
- Portfolio/product sections
- Educational content sections
- Mailing list section
- Footer and navigation links
- Custom styling and layout

## Project Purpose

This project was created to practice frontend development, website layout recreation, CSS styling, JavaScript integration, and frontend debugging using a visual reference.

## Disclaimer

This is an educational and portfolio project. It is not affiliated with, endorsed by, or an official website of Abbott or FreeStyle Libre.
